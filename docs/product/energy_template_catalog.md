Schneider's PM51xx/PM53xx workbook identifies model availability for every selected signal. Its `3000` current register is gateway address `2999`; total active power is register `3060`, not `3054` (phase A). Its float NA encoding is NaN, which the Gateway now omits. The iEM manual gives a hex address alongside each decimal register: `3000` = `0x0BB7`, confirming the same one-based conversion. ABB explicitly states that its hex register address must **not** be decremented and specifies its invalid sentinels. For the other OEM tables, no numeric invalid sentinel is stated for the selected signals; Gateway drops nonfinite float results, and documented drafts require a live signal quality check before any field verification.

## Operating procedure

Run `python manage.py import_energy_catalog --dry-run` to see candidate revisions and the number of devices attached to each legacy entry, then run `python manage.py import_energy_catalog`. The command is repeatable. A changed published map fails import; increment `catalog_revision` for a corrected map. Existing `Device.template_id` values keep their old revision. The command changes legacy selection/verification flags but never reassigns a device; inspect hardware and connection before moving any assignment. The incorrect PM5110 TCP starter has been removed from `initial_templates.json` so a later fixture load cannot restore it; the importer still retires copies already present in a database.

The library and Guided Setup show exact model, protocol, catalog revision, **Documented draft** and an OEM source link. Guided Setup live validation remains required. The Gateway receives read-only Modbus points, static multiplier and invalid sentinels. Documented drafts remain `is_verified=False`; Novena energy-impact calculations and remote writes remain gated on verification. A future **Field verified** promotion must record the physical model/SKU, firmware, wiring and CT/PT setup, Modbus raw readings, meter-display or independent-reference readings, normal operating conditions, and the reviewer/date. Compare each signal's address, function code, signedness, width, word order, scale, unit, invalid-value behavior and energy direction before promotion.
